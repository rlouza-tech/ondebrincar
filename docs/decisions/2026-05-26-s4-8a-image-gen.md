# ADR 2026-05-26 — S4.8a: Geração de imagem via Gemini 2.5 Flash Image

**Status:** Aceito  
**Story:** US-S4.8a  
**Data:** 26/mai/2026  

---

## Contexto

O MVP do Onde Brincar exibe fichas de atração sem foto quando nenhuma imagem real está disponível, recorrendo a um placeholder SVG (US-I2.5). Para melhorar a experiência visual e a percepção de qualidade do produto, a story S4.8a adiciona geração automática de imagem ilustrada ao pipeline.

O plano original especificava **Gemini Imagen 3** como motor de geração.

---

## Decisão

Usar **`gemini-2.5-flash-image`** (Google AI Studio) como motor de geração de imagem, substituindo Imagen 3.

**Prompt parametrizado** em `lib/prompts/image-adapter.ts` com templates de cena por categoria (`teatro`, `parque`, `museu`, `atividade-extra`, `evento`). O nome da atração é inserido como placa/letreiro dentro da cena — não como parte da descrição geral — para garantir composições distintas por categoria.

**Ponto de integração:** `scripts/import-sanity/index.ts`, após a criação do draft Sanity. A imagem é gerada, convertida de base64 para buffer e carregada via `sanityWriteClient.assets.upload()`. O draft é patchado com `foto: { _type: 'image', asset: { _ref: assetId }, alt: '...' }`.

**Fallback:** em caso de falha na geração ou upload, o draft é criado sem foto (placeholder SVG ativo no site), e `image_gen_failed: true` é registrado no report de importação.

**Idempotência:** antes de gerar, o script verifica se o draft já possui `foto` definida. Se sim, pula a geração sem erro.

---

## Alternativas consideradas

| Opção | Motivo de descarte |
|-------|--------------------|
| Gemini Imagen 3 (plano original) | Não disponível na API key do projeto (requer projeto Vertex AI separado) |
| Imagen 4.0 (apareceu no list de modelos) | Usa método `predict` (Vertex AI), não `generateContent` — requer setup adicional e é pago |
| Gemini 2.0 Flash Experimental | Nome depreciado — modelo não encontrado na v1beta |
| Hugging Face FLUX.1-schnell | Gratuito e de qualidade, mas requer nova dependência e novo serviço externo |
| Pollinations.ai | Zero setup, mas sem SLA — inadequado para pipeline de produção |
| Geração manual (prompt → chat → download) | Não escala para novos conteúdos semanais |

---

## Consequências

**Positivas:**
- Mesma API key e SDK (`@google/genai`) já instalados — zero nova dependência
- Qualidade visual validada manualmente com 5 fichas-amostra antes do batch
- Prompts com cena específica por categoria evitam composições repetitivas
- Retry 3x com backoff exponencial para 429/503

**Negativas / riscos:**
- `gemini-2.5-flash-image` é um modelo em preview — Google pode alterar nome, preço ou disponibilidade
- Custo por imagem (~US$ 0,04-0,05) — batch de 55 fichas ≈ US$ 2,50
- Sem controle de seed/reprodutibilidade — reruns geram imagens diferentes
- Geração de imagem aumenta o tempo de execução do `import-sanity` (~10-15s por ficha)

**Mitigações:**
- Idempotência garante que reruns não regeneram imagens existentes
- Fallback transparente mantém o placeholder SVG sem quebrar o pipeline
- Custo monitorado pelo billing do Google Cloud (alertas recomendados)
